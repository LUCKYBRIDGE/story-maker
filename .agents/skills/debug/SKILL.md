# Debug

- Identify the failing input and expected behavior from the affected contract. Trace the execution path before editing.
- Preserve student works, prior Excel compatibility, asset IDs and edit/play separation. Use the current task card and G/A/B/D evidence contract; CI success is reusable only for matching revision and relevant inputs.
- Test one hypothesis with the smallest useful observation or change. Add a focused regression check when practical; use the project's actual gate.
- If another attempt adds no evidence, reassess the cause. Ask the user only when missing input, authority or an external change blocks progress.
- Stop when the failure is resolved and required checks pass. Report the evidence and remaining uncertainty without generating a new investigation report by default.
