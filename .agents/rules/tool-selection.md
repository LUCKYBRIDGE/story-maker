# Tool selection

- Use available read/search tools for source inspection and an available real browser for UI flows; do not require a named MCP server that is absent.
- Ordinary planning, implementation, testing and handoffs follow AGENTS.md. Do not chain generic skills or generate a plan file for every task.
- Use `.agents/skills/debug/SKILL.md` for a bug investigation and `.agents/skills/code-review/SKILL.md` for a requested review or material regression risk; read only the applicable one.
