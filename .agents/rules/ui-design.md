# UI Design Rules & Standards

## 1. 기준

- 색, 글자, 간격, 모서리와 그림자는 `docs/design/tokens.md`만 기준으로 삼는다.
- 학생의 실제 대사·해설 입력이 설명과 설정 조작보다 먼저 보여야 한다.
- 작품, 챕터, 장면 단위 조작을 서로 섞거나 같은 기능을 반복 배치하지 않는다.
- 보조 기능은 없애지 않고 펼치기, 더보기, 팝업으로 단계적으로 드러낸다.

## 2. 상호작용과 반응형

- 필수 터치 목표는 최소 `44px × 44px`이다.
- 모바일(<768px), 태블릿(768~1024px), 데스크톱(>1024px)에서 핵심 흐름을
  유지한다.
- hover에 의존하는 필수 기능을 만들지 않는다.
- 모바일 키보드가 열린 상태에서 입력과 하단 조작이 가려지지 않아야 한다.
- 모달은 초점 이동, 초점 가두기, Escape 닫기와 원래 조작으로의 초점 복귀를
  제공한다.

## 3. 접근성

- 색만으로 오류, 선택, 현재 위치를 표현하지 않는다.
- 필수 정보와 조작 문구는 원칙적으로 12px 미만을 사용하지 않는다.
- 입력의 화면상 이름과 접근 가능한 이름을 일치시킨다.
- 키보드 초점 표시와 화면 읽기용 상태 안내를 제공한다.
- 움직임 감소 환경설정을 존중한다.

## 4. 검증

- 보이는 UI 변경은 390×844, 768×1024, 1024×768, 1440×900 중 영향을 받는
  대표 크기에서 실제 사용자 흐름으로 확인한다.
- 빌드 성공만으로 시각·터치·키보드 동작을 검증했다고 판단하지 않는다.
