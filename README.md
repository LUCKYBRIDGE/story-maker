# 놀퀴즈 스토리 스튜디오

로그인 없이 기기 안에서 쓰고, Excel로 보관하며, 플레이로 고쳐 쓰는 학생용
비주얼 스토리게임 창작 도구입니다. `장(場)`은 이야기의 큰 흐름과 기본 무대를,
`컷(Cut)`은 한 화면의 대사·해설과 개별 연출을 뜻합니다.

## 현재 가능한 일

- 예시 이야기, 이어쓰기 템플릿 또는 빈 작품에서 시작
- 3·4·5단계 이야기 뼈대를 만들고 한 장에 여러 이야기 단계 연결
- 장별 기본 배경·등장인물·화자를 정하고 컷별로 표정·배경 변경
- `대본 전체`와 `컷 꾸미기`를 오가며 같은 장·컷을 이어서 편집
- 캐릭터·배경 검색, 즐겨찾기와 최근 사용 기록
- 편집본을 기기에 자동 저장하고 플레이 버전에 명시적으로 적용
- 체크포인트 복구와 삭제 직후 되돌리기
- 처음부터 또는 원하는 장부터 플레이
- Excel 저장·불러오기와 공개 Google 시트 읽기

기본 제공 이미지의 저작권은 놀퀴즈에 있으며, 이 스토리게임의 작품 제작에
사용할 수 있습니다.

## 실행과 검사

Node.js `>=22.13.0`이 필요합니다.

```bash
npm install
npm run dev
```

기본 개발 주소는 `http://localhost:3000`입니다.

```bash
npm run check
npm run build
npm test
```

공식 빈 Excel 양식은 다음 명령으로 다시 만듭니다.

```bash
npm run template:generate
```

## 저장과 자료 교환

편집본은 현재 브라우저에 자동 저장됩니다. 브라우저 데이터 삭제, 시크릿 모드,
기기 교체까지 복구하는 서버 백업은 아니므로 중요한 작품은 `Excel로 저장`해
별도 보관해야 합니다. Excel은 서버에 업로드하지 않고 브라우저에서 읽습니다.

공개 보기 권한이 있거나 웹에 게시한 Google 시트는 주소로 한 번 읽어 옵니다.
웹에서 시트에 쓰거나 실시간 동기화하지 않습니다. 비공개 시트는 `.xlsx`로
내려받은 뒤 `Excel에서 불러오기`를 사용합니다.

## 공식 Excel 구조

현재 양식은 아래 8개 탭을 사용합니다.

- `시작하기`: 학생·교사용 작성 안내
- `이야기 구성`: 제목, 주제, 인물, 갈등과 3·4·5단계 뼈대
- `장의 흐름`: 장 제목, 여러 이야기 단계, 사건과 다음 장 연결
- `장의 자료`: 장의 기본 배경·인물·화자 후보
- `화자`: 작품에서 다시 쓸 표시 이름
- `컷 대본`: 대사·해설, 화자, 컷별 이미지와 연출 메모
- `창작 메모`: 이야기·장·컷에 연결하는 별도 창작 기록
- `리소스`: 웹에서 고를 수 있는 이미지 목록

화자 이름과 캐릭터 이미지는 서로 독립된 값입니다. 내부 호환 ID는 기존 파일을
계속 열기 위해 `chapter-*`, `scene-*` 형태를 유지하지만 학생 화면과 새 양식에는
`장`, `컷` 용어를 사용합니다. 이전 `작품`, `챕터`, `장면`, `대사` 탭도 계속
읽으며, 다시 저장하면 현재 8개 탭 구조로 바뀝니다.

## 화면 개편 계획(아직 구현 전)

메인 A의 `새 이야기 만들기 / 이어만들기`, 독립 `이야기 구성`, 같은 장·컷을
오가는 편집, 원작을 참고한 플레이를 기존 데이터·저장·Excel 구조에 맞춰
점진 적용합니다. 계정·클라우드는 이번 구현에 포함하지 않습니다.

- [실행 계획과 새 세션 프롬프트](docs/storygame-completion-execution-plan.md#11-u1-화면-정합화-실행-계획)
- [확정/후보별 목업 9개](docs/design/mockups/README.md)
- [화면·데이터 계약](docs/decisions/studio-screen-flow-v1.md)
- [현재 작업 상태](docs/storygame-development-status.md)

이야기 구성은 사용자 위임에 따라 01안(장 목록+선택 상세)을 채택했습니다. 실화면 검증 상태는 U1-01 기준선을 따릅니다.
위 계획을 현재 서비스 화면 구현 완료로 해석하지 않습니다.
