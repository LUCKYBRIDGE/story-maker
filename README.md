# 놀퀴즈 스토리 스튜디오

초등 고학년을 포함한 혼합 연령 학생이 놀퀴즈의 `토끼와 자라`,
`옹고집전` 이미지를 재조합해 대사·해설 중심 스토리게임을 만드는
한국어 웹 스튜디오입니다.

## 현재 가능한 일

- 예시 이야기 또는 완전히 빈 작품에서 시작하기
- 작품 제목과 각 챕터 제목을 학생이 직접 정하기
- 작품 전체에서 다시 쓰는 화자 이름 목록 만들기
- 이미지와 무관하게 글상자 화자 이름 선택하기
- 파일명 드롭다운 또는 썸네일 미리보기로 캐릭터·배경 고르기
- 챕터별 기본 배경·왼쪽 인물·오른쪽 인물 정하기
- 장면별 해설·대사, 화자 위치, 표정·동작, 배경 덮어쓰기
- 챕터의 대사·해설을 `대본 전체 보기`에서 한눈에 편집하기
- 캐릭터와 배경을 나누고 여러 한국어 태그로 이미지 좁히기
- 이미지 즐겨찾기와 최근 사용 기록
- 편집본을 브라우저에 자동 저장하고 플레이 버전에 한 번에 반영하기
- 방금 전 편집본으로 복구하기
- 처음부터 또는 원하는 챕터부터 플레이하기
- 웹 편집본을 Excel로 저장하고 Excel 작품 파일 열기
- 공개 또는 웹에 게시한 Google 시트에서 편집본 불러오기

기본 제공 이미지의 저작권은 놀퀴즈에 있으며, 학생은 이 스토리게임의
작품 제작에 자유롭게 사용할 수 있습니다.

## 시작하기

Node.js `>=22.13.0`에서 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

```bash
npm run check
npm run build
npm test
```

## 저장과 자료 교환

웹 편집은 브라우저의 이 기기 저장소에 자동 저장됩니다. 중요한 작품은
`Excel로 저장`을 눌러 별도 파일로 보관합니다. Excel 파일은 서버에
업로드하지 않고 브라우저 안에서 읽습니다.

공개 보기 권한이 있거나 웹에 게시한 Google 시트는 주소를 붙여 넣고
`시트에서 불러오기`를 눌러 한 번 읽습니다. 웹에서 Google 시트로 쓰거나
실시간으로 감시하지 않습니다. 비공개 시트는 Google 시트에서 `.xlsx`로
내려받은 뒤 `Excel 파일 열기`를 사용합니다.

## 데이터 구조

- `이야기 구성`: 제목, 주제, 인물, 갈등과 단계별 전체 줄거리
- `화자`: 작품에서 다시 쓸 화자 이름
- `챕터 흐름`: 챕터별 줄거리, 역할, 사건과 다음 내용
- `챕터 자료`: 챕터에서 쓸 화자, 캐릭터와 배경
- `장면`: 해설·대사, 화자 이름, 왼쪽·오른쪽 이미지, 장면 배경
- `리소스`: 웹에서 고를 수 있는 이미지 이름

새 Excel 파일은 학생에게 원시 `TRUE/FALSE` 값을 요구하지 않습니다.
이전 템플릿의 `작품`, `챕터`, `사용` 열은 호환을 위해 계속 읽을 수
있습니다. 이전 파일을 웹에서 연 뒤 다시 저장하면 새 탭 구조로 바뀝니다.

화자 이름과 캐릭터 이미지는 독립된 값입니다. 예를 들어
`토끼_놀람.png`를 고르더라도 글상자 이름은 `달토끼`, `민수`처럼
작품을 만드는 사람이 정한 이름으로 표시할 수 있습니다.

## 개발자·교사용 외부 AI 제작

학생용 웹에는 AI 작성 양식이나 자동 생성 기능이 없습니다. 학생은 이야기와
연출을 직접 만듭니다.

개발자나 교사가 외부 AI로 새 예시 작품 초안을 만들 때는
`docs/developer-ai-story-authoring.md`와 구글 시트 템플릿을 함께 전달합니다.
AI 결과는 일반 작품 시트와 같은 구조로 불러오며, 공개 전 사람이 내용과
연출을 검수합니다.
