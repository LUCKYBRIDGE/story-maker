# 놀퀴즈 스토리 스튜디오

로그인 없이 기기 안에서 쓰고, Excel로 보관하며, 플레이로 고쳐 쓰는 학생용
비주얼 스토리게임 창작 도구입니다. `장(場)`은 이야기의 큰 흐름과 기본 무대를,
`컷(Cut)`은 한 화면의 대사·해설과 개별 연출을 뜻합니다.

## 현재 가능한 일

- 토끼와 자라·옹고집전 원작 예시 전체를 읽고, 이어쓰기 템플릿 또는 빈 작품에서 시작
- 3·4·5단계 이야기 뼈대를 만들고 한 장에 여러 이야기 단계 연결
- 장별 기본 배경·등장인물·화자를 정하고 컷별로 표정·배경·장면 연출 변경
- `대본 전체`와 `컷 꾸미기`를 오가며 같은 장·컷을 이어서 편집
- 컷에 2개 또는 3개의 선택지를 만들고, 각 갈래·합류 지점·별도 결말을 연결하여 실제 재생
- 기존 뒷이야기를 특정 선택 갈래 또는 공통 합류 뒤에 연결하고 나중에 도착 컷 재지정
- 글쓰기 옆에 창작 메모를 펼쳐 두고 작품 전체/특정 장 범위로 기록·검색·복원
- 캐릭터·배경 검색, 즐겨찾기와 최근 사용 기록
- 책 앞표지·뒤표지와 작가의 말 꾸미기, 커튼 개막·폐막과 컷 연출 재생
- 편집본을 기기에 자동 저장하고 플레이 버전에 명시적으로 적용
- 체크포인트 복구와 삭제 직후 되돌리기
- 처음부터 또는 원하는 장부터 플레이하고, 재생 중 본 컷을 다시 편집
- Excel 저장·불러오기와 공개 Google 시트 읽기

기본 제공 이미지의 저작권은 놀퀴즈에 있으며, 이 스토리게임의 작품 제작에
사용할 수 있습니다.

## 실행과 검사

Node.js `>=22.13.0`이 필요합니다.

```bash
npm install
npm run dev
```

기본 개발 주소는 `http://localhost:3000`입니다.

```bash
npm run check
npm run build
npm test
```

GitHub Pages용 정적 빌드는 다음 명령을 사용합니다.

```bash
npm run build:github
```

공식 빈 Excel 양식은 다음 명령으로 다시 만듭니다.

```bash
npm run template:generate
```

## 저장과 자료 교환

편집본은 현재 브라우저에 자동 저장됩니다. 브라우저 데이터 삭제, 시크릿 모드,
기기 교체까지 복구하는 서버 백업은 아니므로 중요한 작품은 `Excel로 저장`해
별도 보관해야 합니다. Excel은 서버에 업로드하지 않고 브라우저에서 읽습니다.

공개 보기 권한이 있거나 웹에 게시한 Google 시트는 주소로 한 번 읽어 옵니다.
웹에서 시트에 쓰거나 실시간 동기화하지 않습니다. 비공개 시트는 `.xlsx`로
내려받은 뒤 `Excel에서 불러오기`를 사용합니다.

## 공식 Excel 구조

현재 양식은 아래 8개 탭을 사용합니다.

- `시작하기`: 학생·교사용 작성 안내
- `이야기 구성`: 제목, 주제, 인물, 갈등과 3·4·5단계 뼈대
- `장의 흐름`: 장 제목, 여러 이야기 단계, 사건과 다음 장 연결
- `장의 자료`: 장의 기본 배경·인물·화자 후보
- `화자`: 작품에서 다시 쓸 표시 이름
- `컷 대본`: 대사·해설, 화자, 컷별 이미지·연출·선택/연결 정보
- `창작 메모`: 작품·장·컷에 연결하는 별도 창작 기록
- `리소스`: 웹에서 고를 수 있는 이미지 목록

화자 이름과 캐릭터 이미지는 서로 독립된 값입니다. 내부 호환 ID는 기존 파일을
계속 열기 위해 `chapter-*`, `scene-*` 형태를 유지하지만 학생 화면과 새 양식에는
`장`, `컷` 용어를 사용합니다. 이전 `작품`, `챕터`, `장면`, `대사` 탭도 계속
읽으며, 다시 저장하면 현재 8개 탭 구조로 바뀝니다.

## 현재 개발 상태

공유 기준선은 GitHub `main`입니다. 2026-09-09 기준 최신 제품 커밋은
`67be51a` (`메모 창 조절과 원본 예시 작품, 가까운 컷 이동 개선 (#12)`)입니다.

최신 기준선에서 다음 검증이 통과했습니다.

- GitHub Actions CI: `npm ci` → diff whitespace → `npm run check` → `npm test` 성공
- 전체 Node 회귀 검사: 169/169 통과
- GitHub Pages 정적 빌드·배포 성공
- Chrome 1365×900 / 820×1180 / 390×844에서 최신 메모·근접 컷 이동 검증
- 원작 133/450개 컷 문장 전체 대조, 변환 재생본 136/453개 컷 연결·정규화 검사
- 분기·합류·서로 다른 결말, 저장/Excel/공개 시트 호환 회귀 검사 유지

U1 스튜디오 UI 개편(U1-00~U1-11), U2 이어쓰기 흐름, 장면 연출, 책 표지·커튼,
선택·분기·합류, 첫 화면 반응형, 창작 메모 및 원작 예시 체험은 구현된 상태입니다.
캐릭터 감정 세트 A1-02는 사람의 시각 승인 전까지 `BLOCKED`이며 현재 자동으로
진행할 `READY` 작업은 없습니다.

실제 iOS/Android의 한글 IME·소프트 키보드·Safe Area·실터치는 아직 별도 실기기
검증 항목입니다. 실제 공유 Google 시트 계정 기반 종단 검증과 원작의 서사·연출 품질 검수는 남아 있습니다.
후속 PR #17에서는 도달 가능한 다섯 결말의 대표 경로 자동 재생이 통과했습니다.

현재 제품 범위에는 로그인, 학생 작품 서버 백업, 실시간 공동 편집, Google OAuth,
학생용 AI 자동 작성·이미지 생성, 공개 작품 커뮤니티가 포함되지 않습니다.
선택지 2/3개와 분기·합류는 이미 지원하며, **점수·조건에 따른 선택지 잠금과 의도적인
무한 반복형 게임 흐름**은 현재 범위 밖입니다.

작품은 기기에 저장하고 중요한 결과물은 Excel로 별도 보관합니다.
