- 기준일: 2026-09-04
- 기준 소스: `app/globals.css`
- 목적: 현재 CSS와 선택 목업의 목표 디자인을 구분하고 U1에서 안전하게 이전
- 상태: 공통 셸 토큰은 U1-03에서 구현·검증, 화면별 세부 이전은 U1-04~10 대기

### 1.2 U1 목표 토큰(공통 셸 적용)

네이비 셸·흰 작업면·청록 주요 행동을 사용한다. 아래 값은 목업 픽셀을
그대로 추출한 값이 아니라 구현 가능한 시작안이다. U1-03에서 `.creator-shell`
범위에만 적용했으며 기존 `:root` 색은 일괄 치환하지 않았다.

| 제안 변수 | 값 | 의미 |
|---|---|---|
| --studio-shell | #07162B | 공통 상단, 흰 글자 |
| --studio-bg | #F5F7FA | 작업 공간 바탕 |
| --studio-surface | #FFFFFF | 입력·카드·읽기 영역 |
| --studio-ink | #142033 | 주 본문 |
| --studio-muted | #526174 | 보조 설명 |
| --studio-border | #CBD2DA | 장식 구분선(입력 식별·초점 단독 사용 금지) |
| --studio-control-border | #738197 | 입력·조작 경계 |
| --studio-accent | #006D77 | 주요 행동·선택, 흰 글자 |
| --studio-selected-border | #C76A00 | 현재 장·컷 보조 강조 |
| --studio-selected-bg | #FFF4E5 | 현재 작업 배경 |
| --studio-danger | #B42318 | 오류·위험 행동 |

같은 화면에 민트와 청록을 경쟁하는 주 행동색으로 남기지 않는다. 선택한 항목은
체크·테두리·현재 위치 텍스트를 함께 사용하고 이야기 단계색과 선택색을 구분한다.
대비 목표는 본문 4.5:1 이상, 의미 있는 비문자 조작/초점 경계 3:1 이상이다.
색상표의 숫자만으로 전체 UI 접근성 통과를 주장하지 않는다.

색만으로 현재 상태, 오류, 선택 여부를 표현하지 않는다. 텍스트, 아이콘, 테두리
또는 위치 정보를 함께 사용한다. 새 색상은 기존 토큰으로 표현할 수 없는 의미가
있고 대비를 확인한 경우에만 추가한다.

## 2. 타이포그래피

### 기본 글꼴

```css
Pretendard, "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif
```

이야기 제목처럼 제한된 강조 영역만 다음 계열을 사용할 수 있다.

```css
"Iowan Old Style", "Noto Serif KR", serif
```

### 권장 크기

| 용도 | 크기 | 줄 높이 | 굵기 |
|---|---:|---:|---:|
| 화면 제목 | 28~36px | 1.2~1.3 | 700~800 |
| 영역 제목 | 20~24px | 1.3 | 700 |
| 카드 제목 | 16~18px | 1.35 | 700 |
| 본문·입력 | 16~18px | 1.5~1.7 | 400~600 |
| 보조 설명 | 14~16px | 1.4~1.6 | 500~700 |

학생의 필수 본문·입력은 16px 이상, 부차적 설명도 원칙적으로 14px 이상이다.
플레이 본문은 기본 20~24px를 시작안으로 폭에 맞추되 긴 글을 작은 글자로 숨기지 않는다.
글자 200% 확대를 확인한다. 실제 사용 가능한 글꼴 fallback을 사용하며 새 웹폰트를
자동 추가하지 않는다. 과거 8~12px 규칙은 새 표면으로 가져오지 않는다.

## 3. 간격

4px 기준 격자를 사용한다.

- 미세 간격: 4px
- 같은 요소 안: 8px, 12px
- 입력·카드 안: 16px, 20px, 24px
- 영역 사이: 32px, 48px

새 임의 간격을 만들기보다 위 단계 중 가장 가까운 값을 사용한다.

## 4. 모서리와 그림자

| 용도 | 반지름 |
|---|---:|
| 작은 칩·입력 내부 | 8px |
| 입력·버튼 | 12px |
| 카드 | 16px |
| 큰 패널·모달 | 20~24px |
| 원형 선택 | 9999px |

- 큰 부유 패널: `0 20px 60px rgba(45, 53, 47, 0.12)`
- 작은 카드: `0 8px 24px rgba(45, 53, 47, 0.10)`

그림자는 계층을 설명할 때만 사용하며 카드마다 장식적으로 반복하지 않는다.

## 5. 상호작용

- 필수 터치 목표: 최소 44×44px
- 키보드 초점: 새 표면은 --studio-accent 또는 고대비 이중 외곽선; 어두운 셸에서도 식별
- 비활성 상태: 투명도만 낮추지 말고 가능한 경우 이유를 가까이 표시
- 위험 조작: 새 표면은 --studio-danger, 대상과 결과를 구체적으로 표시, 되돌리기 우선
- 움직임: 짧고 목적이 있어야 하며 `prefers-reduced-motion`을 존중

## 6. 반응형 기준

폭은 뷰포트가 아니라 사용 가능한 컨테이너 공간을 기준으로 한다.
경계는 넓음 ≥1200px, 중간 800–1199px, 좁음 <800px이며 U1-01에서 확정했다.
별도로 낮은 높이(약720px 이하), 가로 화면, 소프트 키보드 상태를 처리한다.

- 넓음: 목록+상세/무대+대본. 본문 가독 폭과 패널 최소 폭을 먼저 정한다.
- 중간: 목록을 접을 수 있게 하며 가로 스크롤 표를 필수 편집 경로로 만들지 않는다.
- 좁음: 장 선택기+선택 상세 한 열, 이미지 선택은 닫기/확인이 유지되는 시트/대화상자.
- 키보드: 무대·설명·불필요한 고정 도구를 접어 입력칸과 현재 위치를 보인다.
- 검증: 1440×900, 1280×720, 1024×768, 820×1180, 390×844,
  844×390, 추가 320px 및200% 확대. 실제 소프트 키보드는 별도 검수한다.

여백은 위4px 체계를 유지하고 모바일 본문 바깥 여백은16px부터 검토한다.
목업의 큰 무대·카드 높이를 고정 px로 복사하지 않는다.

## 7. 적용 원칙

1. U1-03에서 셸 래퍼의 --studio-*를 적용했다. 기존 :root 변수는 일괄 치환하지 않았다.
2. U1-04~10은 해당 화면에 한정해 이전한다. CSS 우선순위 충돌은 중복 규칙을
   쌓아 감추지 말고 영향 범위를 확인해 좁힌다.
3. 색·글꼴·간격을 바꿔도 ID, 저장·Excel, 작품 데이터, 입력 상태를 바꾸지 않는다.
4. 이미 적용한 항목과 미적용 목표를 카드 결과에 기록한다. 전면 디자인 라이브러리
   교체·새 의존성은 이번 작업에 필요하지 않다.
5. 화면별 대표 크기·키보드·긴 글을 실제 확인한 뒤에만 “구현/검증됨”으로 갱신한다.
