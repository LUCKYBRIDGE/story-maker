# 개발자·교사용 외부 AI 작품 제작 양식

이 문서는 학생용 기능이 아니다. 개발자나 교사가 외부 AI로 예시 작품의 초안을
만들 때만 공식 Excel 양식과 함께 전달한다. 학생용 웹에는 AI 작성 기능을 넣지
않으며, 결과는 사람이 내용·연출·연령 적합성을 검수한다.

## 전달할 파일

1. `public/templates/놀퀴즈_스토리_템플릿.xlsx`
2. 이 문서

AI는 8개 탭의 이름과 열 이름을 바꾸지 않는다. `리소스`는 읽기 전용 목록으로
사용하며 수정하지 않는다.

## 복사해서 쓸 요청문

```text
첨부한 놀퀴즈 스토리 스튜디오 Excel 양식으로 선형 스토리게임 한 편을 만들어 줘.

대상: [학년 또는 연령]
주제: [이야기 주제]
분량: [장 수]개 장, 장마다 [컷 수]개 안팎
분위기: [밝음, 익살, 긴장감 등]
교육적 의도: [선택 사항]

반드시 지킬 규칙:
1. 8개 시트 이름과 열 이름을 바꾸지 않는다.
2. 장 ID는 chapter-1부터, 컷 ID는 scene-1부터 작품 안에서 중복 없이 쓴다.
3. 컷의 장 ID와 장의 자료 장 ID는 반드시 장의 흐름에 실제로 있는 ID를 쓴다.
4. 한 장에는 발단·전개·위기·절정·결말 중 여러 단계를 연결해도 된다.
5. 이야기 단계는 쉼표로 구분하고, 이야기 구성에서 선택한 구조의 단계만 쓴다.
6. 컷 종류는 대사 또는 해설, 화자 위치는 왼쪽·오른쪽·해설 중 하나만 쓴다.
7. 대사 화자 이름은 화자 탭의 이름을 쓰고, 해설 컷은 화자 위치와 이름을 해설로 쓴다.
8. 이미지 이름은 리소스 탭에 있는 이름만 정확히 복사한다.
9. 컷 이미지가 장 기본 이미지와 같으면 빈칸으로 두어도 된다.
10. 한 컷의 글은 모바일에서 한 번에 읽기 좋게 짧고 자연스럽게 쓴다.
11. 창작 메모는 플레이 문장과 분리하고, 개인정보를 넣지 않는다.
12. 리소스 탭은 수정하지 않는다.

완성한 .xlsx 파일과 장별 흐름 요약을 제공해 줘.
```

## 8개 탭 작성 계약

| 탭 | 작성 규칙 |
|---|---|
| `시작하기` | 안내를 읽기만 하고 수정하지 않는다. |
| `이야기 구성` | 한 행짜리 표가 아니라 `항목/내용/작성 도움` 형식이다. `내용` 열에 제목, 주제, 갈등, 3·4·5단계 뼈대를 채운다. |
| `장의 흐름` | 장마다 한 행. `장 ID`, `순서`, `장 제목`, `이야기 단계`, `한 줄 사건`, `장의 역할`, `분위기`, `꼭 들어갈 사건`, `다음 장 아이디어`를 쓴다. |
| `장의 자료` | 장 ID별 기본 배경·왼쪽/오른쪽 인물과 해당 장에서 쓸 화자·이미지 후보를 쓴다. |
| `화자` | 플레이 글상자에 표시할 이름을 한 행에 하나씩 쓴다. 이미지 이름과 별개다. |
| `컷 대본` | 컷마다 한 행. ID·장 ID·순서·종류·화자·본문·컷별 이미지·역할·감정·연출 메모를 쓴다. |
| `창작 메모` | 메모와 항목을 한 행씩 쓰고, 필요하면 `연결 장 ID`와 `연결 컷 ID`로 연결한다. 플레이에는 표시되지 않는다. |
| `리소스` | 실제 선택 가능한 이미지의 ID·이름·분류 목록이다. 수정하지 않는다. |

내부 ID가 `chapter-*`, `scene-*`인 것은 이전 작품과의 호환을 위한 기술 규칙이다.
학생에게 보이는 명칭과 설명은 항상 `장`, `컷`을 사용한다.

## 검수 체크리스트

1. 제목·대사·해설이 대상 연령에 맞고 학생의 생각을 대신 결론내지 않는가
2. 장의 이야기 단계가 3·4·5단계 구성과 맞고, 한 장의 여러 단계가 자연스러운가
3. 장·컷 ID가 중복되지 않고 모든 연결 ID가 실제 대상을 가리키는가
4. 화자 이름과 좌우 위치, 대사·해설 구분이 의도와 맞는가
5. 모든 이미지 이름이 `리소스`에 있고 같은 캐릭터의 외형이 일관되는가
6. 장 기본 이미지와 컷 덮어쓰기가 필요한 곳에만 사용됐는가
7. 스튜디오에서 `Excel에서 불러오기` 미리보기를 확인한 뒤 정상적으로 열리는가
8. `플레이에 적용` 후 처음부터와 각 장부터 보아도 흐름이 자연스러운가

AI 결과는 초안이다. 최종 이야기와 연출의 선택권은 제작자에게 있다.
