# 개발자·교사용 외부 AI 작품 제작 양식

이 문서는 학생용 기능이 아니다. 학생은 이야기별 웹에서 제목, 화자, 챕터,
장면, 대사와 이미지를 직접 정한다.

개발자나 교사가 나중에 외부 AI에게 새 예시 작품 제작을 맡길 때만 이 문서와
`이야기별_구글시트_템플릿.xlsx`를 함께 전달한다. AI가 만든 결과도 학생 작품과
똑같은 데이터 구조를 사용하므로 웹에 별도의 AI 모드를 만들지 않는다.

## 1. AI에 전달할 파일

1. `public/templates/이야기별_구글시트_템플릿.xlsx`
2. 이 문서

AI는 템플릿의 시트 이름과 열 이름을 바꾸지 않고 `작품`, `화자`, `챕터`,
`장면` 탭의 내용만 작성한다. `리소스` 탭은 웹에서 실제로 고를 수 있는
이미지 이름 목록이므로 수정하지 않는다.

## 2. 그대로 복사해 쓸 제작 요청

아래 대괄호 부분만 작품에 맞게 바꾼다.

```text
첨부한 이야기별 Excel 템플릿을 사용해 선형 스토리게임 한 편을 만들어 줘.

대상: [학년 또는 연령]
주제: [이야기 주제]
분량: [챕터 수]개 챕터, 챕터마다 [장면 수]개 안팎
분위기: [밝음, 익살, 긴장감 등]
교육적 의도: [선택 사항]

반드시 지킬 규칙:
1. 시트 이름과 열 이름을 바꾸지 않는다.
2. 작품 제목과 챕터 제목은 새로 짓는다.
3. 화자 이름은 캐릭터 이미지 파일명과 독립적으로 정한다.
4. 챕터 ID는 chapter-1부터, 장면 ID는 scene-1부터 중복 없이 쓴다.
5. 장면의 챕터 ID는 반드시 챕터 탭에 있는 ID와 일치시킨다.
6. 종류는 대사 또는 해설, 화자 위치는 왼쪽·오른쪽·해설 중 하나만 쓴다.
7. 이미지 이름은 리소스 탭에 있는 이름만 정확히 복사한다.
8. 장면 이미지가 챕터 기본 이미지와 같으면 빈칸으로 두어도 된다.
9. 한 장면의 글은 모바일에서도 읽기 좋게 짧고 자연스럽게 쓴다.
10. 리소스 탭은 수정하지 않는다.

완성한 엑셀 파일만 별도 파일로 제공하고, 작품의 챕터별 흐름을 짧게 요약해 줘.
```

## 3. 탭별 작성 계약

### 작품

한 행만 사용한다.

| 작품 제목 | 작품 소개 |
|---|---|
| 플레이 화면에 보일 제목 | 작품을 설명하는 한 문장 |

### 화자

대사 글상자에 반복해서 사용할 이름을 한 행에 하나씩 쓴다.

| 화자 이름 |
|---|
| 이야기 속에서 실제로 표시할 이름 |

`토끼_놀람.png`를 장면 이미지로 사용하더라도 화자 이름은 `달토끼`,
`복실이`, `민수`처럼 작품에 맞게 정할 수 있다.

### 챕터

| 필드 | 규칙 |
|---|---|
| 챕터 ID | 영문·숫자·하이픈으로 만든 중복 없는 값 |
| 순서 | 1부터 이어지는 정수 |
| 챕터 제목 | 만드는 사람이 정한 제목 |
| 한 줄 줄거리 | 그 챕터에서 일어날 핵심 사건 |
| 배경 이미지 | 리소스 탭의 배경 이미지 이름 |
| 왼쪽 기본 이미지 | 리소스 탭의 캐릭터 이미지 이름 또는 빈칸 |
| 오른쪽 기본 이미지 | 리소스 탭의 캐릭터 이미지 이름 또는 빈칸 |

### 장면

| 필드 | 규칙 |
|---|---|
| 장면 ID | 작품 전체에서 중복 없는 값 |
| 챕터 ID | 챕터 탭에 실제로 있는 ID |
| 순서 | 각 챕터 안에서 1부터 이어지는 정수 |
| 종류 | 대사 또는 해설 |
| 화자 위치 | 왼쪽, 오른쪽 또는 해설 |
| 화자 이름 | 대사면 화자 탭의 이름, 해설이면 해설 |
| 내용 | 한 번에 읽을 대사 또는 해설 |
| 왼쪽 이미지 | 그 장면에서만 바꿀 때 선택, 아니면 빈칸 |
| 오른쪽 이미지 | 그 장면에서만 바꿀 때 선택, 아니면 빈칸 |
| 장면 배경 | 그 장면에서만 바꿀 때 선택, 아니면 빈칸 |

## 4. 결과 검수

AI가 만든 파일을 바로 학생에게 주지 않고 다음을 확인한다.

1. 작품·챕터 제목과 대사가 연령에 맞는가
2. 모든 이미지 이름이 `리소스` 탭에 실제로 있는가
3. 화자 이름과 좌우 위치가 장면의 의도와 맞는가
4. 해설 장면의 화자 위치와 이름이 모두 `해설`인가
5. 장면의 챕터 ID와 순서가 끊기거나 중복되지 않았는가
6. 이야기별 웹에서 `Excel 파일 열기`로 불러온 뒤 `플레이에 반영`이 성공하는가
7. 처음부터와 각 챕터부터 플레이해도 흐름이 자연스러운가

AI 결과는 초안이다. 최종 이야기와 연출의 선택권은 제작자에게 있다.
