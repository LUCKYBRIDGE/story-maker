# ADR — Story Asset Taxonomy v1

- 상태: Accepted
- 결정일: 2026-08-31
- 범위: Story Maker 기본 제공 캐릭터 이미지 분류와 Picker 탐색

## 배경

Story Maker는 `pinky-ne-site`에서 가져온 캐릭터 이미지를 재사용한다. 같은 캐릭터의 전신·상반신, 감정, 행동, 나이/의상 변형을 한 목록에 평평하게 노출하면 자산이 늘수록 학생이 이미지를 고르기 어렵고 비슷한 이미지가 중복 메뉴처럼 보일 수 있다.

## 결정

캐릭터 이미지는 하나의 기준으로만 분류하지 않고 다음 축을 동시에 가진다.

1. **인물**: 토끼, 자라, 용왕, 의관, 진짜 옹고집 등 동일 캐릭터 묶음.
2. **구도**: 전신, 상반신, 여러 인물. 기존 `StoryAsset.framing`을 유지한다.
3. **감정·상태**: 기본, 기쁨, 슬픔, 화남, 놀람, 걱정, 미안함, 결심, 피곤, 의심, 생각, 아픔, 후회, 안도, 온화, 망설임, 조심, 회상 등.
4. **행동**: 말하기, 도망, 소품 들기, 제안, 명령, 부탁, 건네기, 일하기 등.
5. **변형**: 어린 시절, 젊은 모습, 의상 변형처럼 같은 캐릭터의 의도된 디자인 변형.

기존 작품 호환성을 위해 asset ID, `StoryProject`, Excel 형식은 바꾸지 않는다. 현재 단계에서는 기존 `StoryAsset.tags`에 사람이 읽을 수 있는 분류 태그를 추가하여 기존 Picker의 태그 필터를 그대로 활용한다.

예:

- `인물 · 토끼`
- `감정·상태 · 놀람`
- `행동 · 말하기`
- `변형 · 어린 시절`

## 자산 제작 원칙

- 같은 캐릭터는 얼굴, 체형, 색, 의상과 상대 비율을 일관되게 유지한다.
- 가능하면 핵심 캐릭터의 Canonical Master는 전신으로 확보한다.
- 상반신 이미지는 대화·감정 강조용 자산으로 계속 활용한다.
- 의미가 거의 같은 중복 이미지는 신규 Picker에서 대표 이미지 중심으로 노출한다.
- 어린 시절/젊은 모습처럼 비율이 의도적으로 다른 이미지는 일반 기본형과 별도 변형으로 분류한다.
- 향후 Story Pack 구조로 이동할 때 동일 taxonomy를 pack manifest의 정식 메타데이터로 승격한다.

## 현재 구현

`app/story-asset-taxonomy.ts`가 기존 카탈로그를 비파괴적으로 분류하고, `StoryStudioWithAssetTaxonomy`에서 현재 Picker가 읽는 `tags`를 보강한다. 따라서 로컬 저장본과 기존 Excel을 마이그레이션하지 않고도 분류 체계를 먼저 사용할 수 있다.

## 후속 작업

1. Picker에서 `인물 → 구도 → 감정·상태 → 행동`을 독립 필터 그룹으로 시각적으로 분리한다.
2. 자산 감사 결과에 따라 `KEEP / NORMALIZE / HIDE / REFERENCE-REMAKE / REPLACE` 품질 상태를 manifest에 추가한다.
3. 토끼·자라 등 핵심 캐릭터에 Canonical 전신 기본 세트를 보강한다.
4. Story Pack 도입 시 현재 런타임 분류 규칙을 정적 manifest 데이터로 이전한다.
