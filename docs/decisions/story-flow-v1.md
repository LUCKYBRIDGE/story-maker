# 컷 선택·연결과 분기·합류 v1

- 결정: 2026-09-09 사용자 요청. 기존 선형 지원은 보존한다.
- 책임: 데이터 신뢰성, 교육 UX·QA 검토 관점.

StoryLine의 선택적 flow는 choice(고유 ID·문구·도착 컷을 가진 선택지 2/3개) 또는
goto(도착 컷)이다. 필드가 없으면 정렬된 다음 컷, null 도착지는 끝,
빈 문자열은 아직 정하지 않은 연결이다. 순번 대신 안정 ID로 연결하므로 명시적 연결은
장·컷 순서 변경에도 유지된다. 명시하지 않은 연결은 현재 표시 순서를 따른다.

선택은 현재 컷의 문장을 읽은 뒤 표시한다. 선택점에서 다음/키보드 진행은 막고 선택만 허용한다.
이전 탐색은 방문 ID 이력을 사용하며 새 선택 시 이전에 지나온 갈래로 강제 진행하지 않는다.
장 골라 시작은 이력을 초기화한다. 잘못된 링크는 재생 단계에서도 다른 컷으로 대체하지 않는다.

편집본은 빈 문구·미정 연결을 보존한다. 플레이 적용 시 빈 선택 문구·끊긴 연결·순환을 안내한다.
삭제는 외부의 연결을 빈 문자열로 바꾸고 복구 기록으로 이전 작품을 되돌릴 수 있다.
추가·복제·분할은 기존 outgoing flow를 새 마지막 컷으로 옮긴다.
연결된 컷의 문장 병합은 목적지와 선택 시점을 잃을 수 있어 거부한다.

자동 갈래 준비는 각 갈래 장과 합류 장에 빈 해설 컷을 만든다. 합류 뒤에는 원래 다음 컷을
잇고, 기존 마지막 컷이 새 갈래로 흘러들지 않도록 끝 연결을 명시한다.
기존 연결은 유지하며 학생의 내용을 대신 작성하지 않는다.

문서 봉투 v1과 공식 Excel 8탭을 유지하고 선택적 필드/컷 대본 후미 열만 추가한다.
Excel 도착지는 컷:ID 또는 끝, 빈칸은 미정이다. 이전 빈 열 파일은 선형이다.
존재하지 않는 목적지 ID나 잘못된 선택 구조를 읽으면 원본 보존과 위치 안내 후 가져오기를 거부한다.

참고: pinky-ne-site 폴더는 기획 문서만 포함한다. 실제 참고는
pinky-ne-site-publish/worker/story-data/stories.js의 두 원작 선택 정규화 부분이다.
각 option의 nextStep을 nextRoute로 연결하는 의미만 참고하고 서버 API·점수·계정 구조는 도입하지 않았다.

기존 뒷이야기가 있으면 갈래를 준비하기 전에 연결 위치를 고른다. ‘모든 갈래가 합쳐진 뒤’ 또는
‘선택지 1/2/3의 줄거리’가 가능하다. 특정 선택지에 배정하면 그 선택은 기존 첫 뒷컷으로 바로
연결하고 해당 갈래의 빈 장은 만들지 않는다. 기존 글·컷 ID·소속 장과 기존 결말 연결을 보존한다.
다른 갈래는 새 합류 지점으로 연결하며, 기존 뒷이야기도 합치려면 원하는 끝 컷에서 도착 컷을
새 합류 지점으로 지정한다. 창을 취소하면 변경하지 않는다.
