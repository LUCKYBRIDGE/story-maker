## CF-01 — 빈 작품에서 첫 플레이

1. `새 작품 만들기`에서 제목과 첫 장을 만든다.
2. `대본·컷 쓰기`에서 대사 컷을 추가하고 화자와 본문을 입력한다.
3. `플레이에 적용`한 뒤 플레이를 연다.

기대: 새 컷 본문에 초점이 보이고 자동 저장 상태가 갱신된다. 적용 뒤에만 제목과
대사가 플레이에 보이며 구상·창작 메모는 보이지 않는다.

## CF-02 — 이어쓰기와 플레이 분리

1. `토끼와 자라` 이어쓰기 템플릿을 연다.
2. 안내된 첫 빈 컷에 문장을 쓰고, 적용 전에 플레이를 확인한다.
3. 편집으로 돌아와 적용한 뒤 다시 플레이한다.

기대: 준비된 앞이야기와 편집 위치가 유지되고, 새 문장은 적용 전에는 보이지 않으며
적용 뒤에만 순서대로 보인다.

## CF-03 — 창작 메모 왕복

1. 편집 중인 장·컷을 기록하고 창작 메모를 연다.
2. 사건·갈등 도움 틀로 메모를 만들고 검색·수정한다.
3. 메모를 닫고 플레이를 확인한다.

기대: 같은 장·컷과 스크롤 위치로 돌아오고 Dialog 초점은 열었던 조작으로 복귀한다.
메모는 저장되지만 플레이에는 보이지 않는다.

## CF-04 — Excel 저장·다시 불러오기

1. 제목, 여러 단계가 연결된 장, 컷, 창작 메모가 있는 작품을 Excel로 저장한다.
2. 별도 테스트 프로필에서 파일을 선택하고 미리보기를 확인해 연다.
3. 이야기 구성, 장의 흐름·자료, 컷 대본, 창작 메모를 비교한다.

기대: 공식 8개 탭을 거쳐 공백·줄바꿈·연결 ID·이야기 단계가 보존된다. 가져온
편집본은 명시적 적용 전 플레이본을 조용히 바꾸지 않는다.

## CF-05 — 잘못된 파일 뒤 작품 보호

1. 적용된 테스트 작품에서 빈 파일 또는 손상된 `.xlsx`를 선택한다.
2. 오류 위치와 고치는 법을 확인하고 현재 편집·플레이를 다시 연다.

기대: 탭·행·열·잘못된 값을 포함한 안내가 보이고 해당 입력으로 이동할 수 있다.
현재 편집본과 플레이본은 그대로다.

## CF-06 — 새로고침 뒤 기기 저장 복원

1. 제목·장·대사 컷을 만든 뒤 `기기에 저장됨`을 확인한다.
2. 새로고침 후 `이 기기의 저장된 작업 이어하기`를 누른다.

기대: 버전 문서 봉투에서 본문이 복원된다. 마지막 장·컷의 재접속 복원은
현재 코드에서 별도 저장을 확인하지 못했으므로 U1-02에서 추가 검증할 목표다.
기존 CF-06 자동 검사 통과만으로 위치 복원까지 통과했다고 판단하지 않는다. 브라우저 데이터
삭제·시크릿 모드·기기 교체는 복구 범위가 아니며 Excel 보관 안내가 보인다.

## CF-07 — 모바일 글쓰기·메모·플레이

1. 390×844에서 컷 본문을 두 문장 이상 입력하고 실제 소프트 키보드를 연다.
2. 창작 메모를 쓰고 닫은 뒤 컷을 추가·적용한다.
3. 긴 대사를 플레이에서 읽고 앞뒤 이동한다.

기대: 입력칸과 주요 조작이 키보드에 가려지지 않고, 44px 터치 목표가 겹치지 않는다.
긴 글은 말풍선 영역에서 읽을 수 있으며 다음 컷 조작이 가능하다.

## CF-08 — 한 장의 여러 이야기 단계

1. 5단계 구성에서 한 장에 `위기`, `절정`을 함께 연결한다.
2. 장-단계 흐름표, 대본, 컷 꾸미기, 메모에서 라벨을 확인한다.
3. 4단계와 3단계로 바꿨다가 5단계로 돌아온다.

기대: 한 장의 여러 단계가 동시에 표시된다. 현재 구조에 없는 연결은 숨겨져도 데이터는
보존되며, 돌아왔을 때 복구된다. 미연결 장은 강제 오류가 아닌 성찰 안내로 보인다.

## CF-09 — 여러 단계의 Excel 왕복

1. 여러 단계가 연결된 작품을 Excel로 저장한다.
2. `장의 흐름`의 `이야기 단계` 셀을 확인하고 다시 불러온다.
3. 미리보기 뒤 편집본으로 열어 적용·플레이한다.

기대: 쉼표·가운뎃점·줄바꿈 형식을 읽고 표준 쉼표 형식으로 내보낸다. 알 수 없는
단계는 위치와 고치는 법을 안내하고, 유효한 다중 단계 순서와 플레이는 보존된다.

### CF-11 — 구성·장·단계·Excel 보존

### CF-12 — 플레이와 두 복귀 의미

1. 편집에서 컷을 선택하고 플레이를 열어 다음 컷으로 이동한다.
2. 편집으로 돌아가기를 눌러 원래 보기로 복귀하는지 확인한다.
3. 다시 재생 중 `이 컷 고치기`를 눌러 해당 컷 안정 ID로 편집기에 복귀하는지 확인한다.
4. 예시 플레이 왕복 뒤 학생 저장본이 그대로인지 확인한다.
5. 버튼·장 선택기에 초점을 둔 키 입력이 의도하지 않은 컷 이동을 하지 않는지 확인한다.
