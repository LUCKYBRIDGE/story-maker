# 교실 파일럿 준비용 내부 QA 보고서

- 기준일: 2026-09-03
- 상태: 실제 학생 대상 파일럿이 아닌 자동 검사·내부 시나리오 점검 기록
- 주 책임: QA·릴리스 책임자
- 필수 검토: 교실 운영 교사, 학생 대변인, 접근성·개인정보 보호자

## 증거 범위

이 저장소에는 학생 6명이 실제 기기로 참여했다는 동의 기록, 원본 관찰 로그,
실행 시각, 캡처 같은 검증 자료가 없다. 따라서 이전 문서의 학생 A~F 기록,
전원 성공이라는 완수율, 평균 도달 시간과 교사 개입 횟수는 확인된 실제 파일럿 결과로
간주할 수 없어 제거했다.

현재 확인 가능한 증거는 다음뿐이다.

- `tests/core-user-flows.test.mjs`의 CF-01~CF-09 자동 상태·데이터 흐름 검사
- 정적 검사, 프로덕션 빌드와 전체 Node 회귀 테스트
- 코드에 구현된 Dialog 초점 복귀, 플레이 키보드 이동, reduced-motion 처리
- 문서에 정의된 데스크톱·태블릿·모바일 수동 검토 절차

이 증거로 자동 검사 범위의 P0 결함이 0건이라고 말할 수는 있지만, 실제 교실의
과제 완수율이나 첫 플레이 시간을 주장할 수는 없다.

## 내부 QA에서 닫힌 Top 3 Issues

1. 이어쓰기 템플릿 시작 위치와 대본↔컷 꾸미기 왕복
   - 안정 ID 기반 위치·스크롤·본문 초점 복원과 삭제 시 안전한 대체 위치를 구현했다.
2. 잘못된 Excel·Google 시트의 원인과 수정 방법
   - 탭·행·열·입력값·고치는 법이 있는 오류와 열기 전 미리보기로 현재 작품을 보호한다.
3. 마우스 없는 Dialog·플레이 조작
   - Dialog Escape/Tab 포커스 트랩·복귀와 플레이 방향키·Space·Escape를 지원한다.

## 실제 파일럿 전 필수 확인

- iPad Safari와 Android Chrome에서 소프트 키보드가 입력칸·하단 조작을 가리지 않는지
- 10~20개 장, 장당 20개 이상 컷인 작품의 편집·저장·플레이 지연
- 브라우저 저장 용량 부족과 손상 저장본에서 학생이 Excel 복구 안내를 이해하는지
- 44px 터치 목표, 색 대비, 긴 대사와 보조기기 읽기 순서
- 실제 `.xlsx` 다운로드·재업로드 및 학교 네트워크의 공개 시트 접근

## 개인정보 보호 원칙

- 보호자·학교 동의 없이 학생의 실명, 학번, 얼굴, 음성, 창작 본문을 수집하지 않는다.
- 꼭 필요한 관찰 항목과 익명 ID만 쓰고, 보관 기간·접근자·삭제일을 사전에 정한다.
- 캡처에는 개인정보, 비공개 시트 URL, 실제 학생 작품 원문을 남기지 않는다.

## 판정

현재 상태는 `내부 회귀 검사 통과, 실제 교실 파일럿 미실행`이다. 실제 학생 관찰과
대표 기기 수동 검토를 마치기 전에는 “교실 기준 완전 충족”이나 “릴리스 검증 완료”로
표현하지 않는다. 실행 결과는 `docs/qa/core-user-flows.md` 양식으로 증거와 함께 갱신한다.
